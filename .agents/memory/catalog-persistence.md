---
name: Store persistence
description: The user's durability requirement for the SK3LE WATERMARK BOT catalog and uploaded files.
---

Catalog products and uploaded media must remain available indefinitely after they are added; only explicit deletion should remove them.

**Why:** The user called persistence their number-one requirement.

**How to apply:** Keep product records and media in durable storage rather than process memory or local-only files. Avoid automatic re-seeding that restores intentionally deleted catalog entries.
